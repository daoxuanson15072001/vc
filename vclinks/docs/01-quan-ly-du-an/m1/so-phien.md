- **Ai ghi:** mỗi phiên Claude Code tự cập nhật dòng của mình khi mở phiên, khi xong (commit cùng nhánh với code), khi tách phiên (`M1b-04a`, `M1b-04b`) và khi có lần sửa (`.fix-<n>`).

- **Tránh conflict giữa hai agent:** mỗi nhánh chỉ sửa dòng của phiên mình; không sắp xếp lại bảng.
- **Model và nhịp:** cột "Nhịp · Agent" và "Model đầu" lấy từ kế hoạch §4.3–4.4; cột "Nâng model" ghi mỗi lần nâng theo dấu hiệu D1–D4 (kế hoạch §4.2).

## Cách ghi

Cập nhật khi mở, khi xong, và mỗi lần sửa. Trạng thái: ⬜ chưa làm · 🔵 đang làm · 🟡 chờ gác cổng · ✅ xong · ⛔ bị chặn (ghi đầu vào thiếu).

| Khi nào | Ghi gì |
|---|---|
| Mở phiên | Trạng thái 🔵, Nhánh `m1/<mã>-<slug>`, Người chạy (ghi `Agent 1` / `Agent 2`) |
| Code xong, chờ gác cổng | Trạng thái 🟡 |
| Gác cổng đã gộp vào `main`, đạt hết "Xác nhận xong" | Trạng thái ✅, Commit gộp (mã 7 ký tự), Xong ngày `dd/mm/yyyy` (phiên gác cổng ghi) |
| Bị chặn | Trạng thái ⛔, ghi đầu vào thiếu (E1–E8 hoặc phiên trước) vào "Việc phát sinh" |
| Nâng model (§4.2 kế hoạch) | Cột "Nâng model": `Sonnet→Opus · D2 · dd/mm HH:mm`, cách nhau bằng `;`; mở phiên `.retry-<n>` thì ghi thêm tên phiên mới |
| Dừng cắt lỗ (Fable vẫn trượt) | Trạng thái ⛔, "Việc phát sinh" ghi vướng gì; chờ chủ dự án chọn tách phiên / giảm phạm vi / hỏi người ngoài |
| Xong một nhịp (phiên gác cổng) | Một dòng ở [Nhật ký nhịp](#nhật-ký-nhịp) |
| Sửa sau khi xong (§1.3 của kế hoạch) | Cột "Lần sửa": `.fix-<n> · <việc> · <mã commit gộp>`, cách nhau bằng `;` |
| Tách phiên | Thêm dòng `<mã>a`, `<mã>b` ngay dưới dòng gốc, dòng gốc ghi "tách" ở "Việc phát sinh"; thêm dòng Lịch sử cập nhật |
| Việc ngoài phạm vi | Cột "Việc phát sinh": mô tả ngắn, không tự làm |
